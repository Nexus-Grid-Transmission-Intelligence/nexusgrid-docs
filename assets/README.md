# Nexus Grid Assets

This directory contains supporting visual materials used by the Nexus Grid public demonstration environment.

## Contents

- [Restoration Progression Visualization](restoration_progression.webp)
- [Restoration Comparison Chart](restoration_comparison.webp)
- [Plateau Detection Demonstration](restoration_plateau.webp)
- [Operational Trace & Orchestration Screenshot](orchestration_cli.webp)

## Purpose

These assets support public documentation, methodology review, demonstration interpretation, and infrastructure coordination discussions.

Assets are intended to illustrate modeled behavior within the Nexus Grid demonstration environment.

## Demonstration Boundary

Visual assets are provided for review and communication purposes.

They should not be interpreted as evidence of:

* Production deployment
* Utility adoption
* Field-validated operational performance
* Outage reduction
* ROI improvement
* Automated operational control

Refer to the Validation Boundaries and Methodology documents for additional context.
